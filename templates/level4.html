Level 4: Chamber of Encryptions

In this level, you must encrypt three different data crystals. Each crystal appears one by one. The second crystal appears only after the first one is encrypted. The third crystal appears only after the second one is encrypted.

Encryption Rule Used in This Level:
All data uses Caesar Cipher +3.
This means every letter moves 3 letters forward:
A → D, B → E, C → F
S → V, T → W, U → X
1. Collect the Data Crystal 💎

Each crystal contains plaintext. Plaintext is readable and unsafe.

2. Collect the Key 🔑

Each mission has an encryption key. Collect it before using the machine.

3. Use the Machine ⚙️

Stand near the machine and press E. The game pauses while you type the ciphertext manually.

4. Avoid the Red Spirits 👻

The red spirits move around the whole field. Avoid them while carrying plaintext.

Trust Level is your safety/health. It decreases when plaintext is exposed, when spirits catch you before encryption, or when the wrong ciphertext is entered.
