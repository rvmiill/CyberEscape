# CyberEscape

CyberEscape is a gamified cybersecurity awareness platform developed as a Final Year Project.

## Technologies Used
- Python Flask
- HTML
- CSS
- JavaScript
- SQLite

## Features
- User Authentication
- 5 Interactive Cybersecurity Levels
- Leaderboard
- Analytics Dashboard
- Certificate Generation

## Installation

1. Install requirements:
   pip install -r requirements.txt

2. Run the application:
   python app.py
